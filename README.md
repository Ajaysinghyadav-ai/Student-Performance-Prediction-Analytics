# Student Performance Prediction & Analytics

## Project Overview
This project uses Python and Machine Learning to analyze student performance, predict final exam scores, classify students into Pass/Fail categories, and group students using clustering.

## Objectives
- Analyze student performance data.
- Predict final exam scores using Linear Regression.
- Classify students as Pass or Fail using Logistic Regression.
- Identify student groups using K-Means Clustering.
- Visualize patterns in the dataset.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
1. Linear Regression
2. Logistic Regression
3. K-Means Clustering

## Dataset
The project uses a synthetic dataset containing study hours, attendance percentage, previous exam scores, assignment scores, and final exam scores. It is intended for educational purposes.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries:
   `pip install pandas numpy matplotlib scikit-learn`
3. Keep the notebook and `student_performance.csv` in the same folder.
4. Open the notebook in Jupyter and run the cells in order.

## Disclaimer
The dataset is synthetic, and the results are for educational demonstration only. Model performance may differ on real-world student data.
